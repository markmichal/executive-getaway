# Executive Getaway 2027

One-page site for the Cru High School Executive Getaway, June 24 to 27, 2027, at the Historic Stanley Hotel in Estes Park, Colorado.

- `index.html` is the whole site. No build step. Open it in a browser to preview.
- `ds/cru-cornerstone/` is the Cru Cornerstone design system (fonts, logo, components). Don't edit it.
- `img/` holds the photos. Every photo that didn't come from Linda's Drive folder is logged in `img/CREDITS.md`.
- `HANDOFF.md` has the design rules, facts to keep exact, and the list of what's still open.

Purple dashed tags (`.ph` and `.pht`) mark content we're still waiting on. Leave them in place until the real content replaces them.

## Publishing

Hosted on GitHub Pages from the `main` branch, root folder. The empty `.nojekyll` file tells GitHub to serve the files as they are.
